# Suggested Commands

## System
- Platform: Linux
- Dev environment: `devbox shell` (or `devbox run <command>` from outside)
- Standard utils: `git`, `ls`, `find`, `grep` available

## Project Commands
No build/lint/test pipeline — this is a Markdown-only knowledge repo.

- Find TODOs: `rg "TODO|FIXME" .`
- Word counts: `wc -w **/*.md`
- Check links (if needed): manual or use a markdown link checker

## Git
- Conventional commits: `docs(postgresql): explain MVCC snapshots`
- Never commit without user review
- Keep file map in CLAUDE.md in sync after structural changes

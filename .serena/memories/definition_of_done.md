# Definition of Done

When a note-writing or editing task is completed, verify:

## Content Checks (from styleguide.md §8)
1. No styleguide meta-terms leaked into text
2. No self-referential commentary about document structure
3. No terms used before definition
4. Every mechanism traced to observable effect
5. Code anchors bound to human concepts (what + where + why)
6. Scenario threads through the note; details appear when scenario needs them
7. Layered disclosure for 3+ interdependent components
8. Cross-layer references instead of duplication

## Structural Checks (from structure-guide.md)
1. File numbered correctly by dependency order
2. Prerequisites section with links present
3. `index.md` of parent folder updated (links, study order, "Как всё связано")
4. Cross-references to related files in other folders added
5. CLAUDE.md file map updated if structure changed
6. Cascading changes checked: neighboring files' narrative entries still valid

## Before Submitting
- Never commit without user review
- Conventional commit format: `docs(topic): brief description`

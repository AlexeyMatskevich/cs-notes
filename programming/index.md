# Программирование

**Предпосылки:** нет.

Этот раздел — входная точка для всего репозитория. Он объясняет, как человек записывает действия для компьютера, какие инструменты для этого появились и какие ограничения каждого инструмента становятся заметны по мере роста программы.

Материал строго однопоточный: без async (асинхронного выполнения) и без multithreading (параллельных потоков). Сначала здесь появляется базовая модель программы, данных и управления, а уже потом на неё опираются остальные разделы.

## Как запускать примеры

Примеры в этом разделе написаны на Ruby — динамическом языке с лаконичным синтаксисом, удобным для обучения. Если хочется запустить пример без локальной установки Ruby:

1. Откройте https://onecompiler.com/ruby
2. Вставьте код из файла из `programming/examples/`
3. Нажмите `Run`

Для простоты в этом разделе это основной путь. Если Ruby уже установлен локально, тот же файл можно запустить командой `ruby file.rb`.

## Как всё связано

**Память человека vs объём деталей.** Адреса, копии формул и промежуточные состояния можно держать в голове только до определённого масштаба. Переменные, функции, коллекции и классы уменьшают объём деталей, которые нужно помнить одновременно.

**Прямое изменение vs контролируемые операции.** Когда данные можно менять из любого места, код остаётся коротким, но труднее читать и отлаживать. Методы, инкапсуляция и неизменяемые преобразования уменьшают количество скрытых точек изменения.

**Скорость правки vs ранняя проверка.** [Динамические языки](02-variables-and-types.md) позволяют быстро менять код и сразу запускать его. [Статические проверки и компиляция](12-compilation-and-interpretation.md) требуют больше подготовки, но часть ошибок ловится до запуска.

**Этот раздел — фундамент.** [Основы представления данных](../foundations/index.md) объясняют, почему ячейка хранит 0–255, как устроены отрицательные числа и дроби, и откуда берётся 0.1 + 0.2 ≠ 0.3. [Аппаратное обеспечение](../computer/index.md) углубляет модель процессора и памяти, [алгоритмы и структуры данных](../algorithms-and-data-structures/index.md) раскрывают внутреннее устройство коллекций, а [Ruby](../ruby/index.md) показывает, как эти идеи реализованы в конкретном языке.
